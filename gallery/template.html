Isles境

Each isle is designed from its own brief and written as one world file. The engine supplies the glass, the day and night, the lens, the mist and the soil cross-section; everything inside is made fresh.

每一境都从自己的境帖出发，写成一个世界文件。玻璃、昼夜、镜头、薄雾和土层剖面由引擎负责，里面的东西每一境重新做。

The brief境帖

Fill in the marked slots and hand it to your agent. Leave out what you do not care about; the agent fills the gaps and reads the plan back before it starts.

把标出来的空填上，交给你的代理。不在意的槽位直接删掉，代理会补上，并在开工前把方案复述给你确认。

Use it用法

NEO-Isle is a skill for coding agents, built and tuned with Claude Code. It needs Python 3 and Google Chrome; an isle loads three.js from a public CDN when it runs.

NEO-Isle 是给编程代理用的技能，用 Claude Code 做出来、调出来的。需要 Python 3 和 Google Chrome；每一境运行时从公共网络加载 three.js。

Install安装

npx skills add {{REPO}} -g -a claude-code
git clone https://github.com/{{REPO}} ~/.claude/skills/neo-isle

Either one. Every isle you make is yours: no watermark, no credit line.
两种任选其一。你做出来的每一境都归你，不加水印和署名。

Then say然后直接说

Make an isle: a miniature harbour city at dusk, in a glass dome on a desk.做一境：黄昏的微缩港口城市，装在玻璃钟罩里，放在桌面上。

Make the next isle. Give me three subjects to choose from first.做下一境，先给我三个题材挑。

It asks once, about what only you can decide, then plans, builds, checks renders at four hours of the day, and hands over a versioned page with a cover.
它只问一轮你才能定的事，然后写方案、造境、在四个时辰出图检查，交付带版本号的网页和封面。
