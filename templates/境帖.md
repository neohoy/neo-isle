# 境帖：点一境

把下面这段话里双花括号的地方填上，交给代理就行。不想填的槽位直接删掉那半句，代理会替你补，并在开工前复述给你确认。

## 内容（这一境里有什么）

```
方寸之境 · {{境名}}：
{{地貌：最高处是什么，最低处是什么}}；
{{水：河 / 湖 / 海 / 泉 / 冰，或者用什么代替水}}；
{{主体植被：一种}}；
{{主角生灵}}正在{{做什么}}，另有{{配角一两种}}；
{{一处人迹：小建筑或器物}}；
{{天气与空气：雾、云、雨雪、风}}；
一奇：{{一件不可能、却很安静的事}}；
色调{{三四个主色}}，点缀{{一个点缀色}}；
最美在{{拂晓 / 晨光 / 正午 / 黄昏 / 夜晚}}。
```

## 外观（这一境长什么样）

每项从给出的预设里选一个，不写就用第一个。

```
容器：{{玻璃立方体 / 玻璃钟罩 / 玻璃球}}
背景：{{深空 / 桌面 / 纯色（写出颜色）}}
光效：{{适中 / 柔和 / 强烈}}
系列名：{{方寸之境，或者你自己的系列名}}
题记：{{标题下面的一句话}}
```

## 例

```
方寸之境 · 雪落寒山：
左后一座尖削的孤峰，前面是雪原和一面冰湖；
水全部封冻，岩阶上挂一幅冰瀑；
挂雪的云杉；
牦牛群正在排成一行走过雪原，另有一只赤狐、几只寒鸦；
一间压着厚雪的石屋，屋旁拉着五色经幡；
全天落雪，云低压着山头；
一奇：入夜后，冰面下有发光的鱼在游；
色调雪白、冰蓝、岩灰蓝、松墨绿，点缀暖橙；
最美在黄昏。

容器：玻璃球
背景：桌面
光效：适中
```

## 想改的不止这些

- 想换成预设里没有的容器、背景或质感，或者想要一套完全是自己的风格：告诉代理“我要自成一格”，它会把引擎复制一份到你的系列目录里改，之后你的每一境都用这一套。
- 想改某一境里已经做好的某样东西：直接说“把牦牛换成驯鹿”“湖再大一点”，代理改完会升一版，不覆盖旧的。
