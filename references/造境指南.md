# 方寸之境 · 造境指南

这一境要做什么，在写代码之前想清楚。本文讲五件事：提示词（境帖）怎么读和怎么写、九个槽位、外观怎么选、一奇、布局。最后是候选题材。

## 一、提示词

### 原始提示词和它的问题

这个系列最初来自这样一段话：

> 一个3D微缩生态场景html，一方独立世界，悬浮在深空中的透明玻璃立方体内部，包含雪山、蜿蜒河流、瀑布、lush 森林、草地、小湖泊、微型动物、漂浮云朵与薄雾，内部有柔和昼夜过渡光，玻璃边缘折射微光，等距视角，微距摄影感，移轴效果，电影级体积光，柔和高光与轮廓光，精致黏土与半透明材质，梦幻、宁静、魔法现实主义，超精细，桌面微缩摆件质感，背景深色虚化。

它做出了第一境，但它是按生图提示词的写法写的（一串并列的关键词），用来做一个系列有七处要改：

1. **固定项和变化项混在一起。** 移轴、昼夜、体积光这些每一境都一样，雪山、河流、森林只属于这一境，容器和背景则是可以换几种的。混着写，换题材时不知道该换哪些词。→ 分成三类：引擎保证的不写；内容自由写；外观从预设里选。
2. **只有名词清单，没有关系。** “雪山、河流、瀑布、湖泊”没说河从哪来到哪去。做成什么样全凭运气。→ 写成一句有因果的话：雪线化水，越崖成瀑，绕过草甸入湖。
3. **“魔法现实主义”没有落点。** 第一境里除了玻璃立方体本身，没有一件真正不可能的事。→ 每一境指定一件具体的奇事（见第三节）。
4. **不能验证的形容词。** “超精细”“电影级”“梦幻”在代码里没有对应物。→ 换成看得见的东西：近千棵树、土层剖面、晨昏的光柱、夜里的三种光。
5. **互相打架的词。** “等距视角”是没有透视的，“微距摄影感”和“移轴”又需要纵深。→ 系列里定为 20° 窄视角透视加移轴，两头都照顾到。
6. **缺了最出效果的一项。** 原文没提土层剖面，而“桌面摆件质感”主要就靠它。→ 已经固定进引擎。
7. **没有写怎么算做完。** 没有交互、检查和交付的要求。→ 技能流程里规定了四个时辰出图检查、带版本号交付、出封面。另外原文里的 `lush` 是中英夹杂，写成“茂密的”。

### 境帖：系列提示词模板

给用户看的版本在 `templates/境帖.md`（一段填空的话加一个例子），用户不知道怎么开口时把它发给他。下面是同一份模板的逐项版本，用它来读用户贴来的任何提示词：把内容拆进这些槽位，缺的你来补。

网上流传的同类模板常见的槽位是：承载容器、元素列表、光照效果、材质组合、艺术风格与情绪、背景。对到这里：“元素列表”拆成下面内容部分的七项；“承载容器”“背景”对到外观预设；“光照效果”对到光效强弱和最美时辰；“材质”和“艺术风格”是引擎保证的（黏土与半透明、宁静精致），用户要别的就走 `自成一格.md`。

```
方寸之境 · 第 N 境 · 〈境名〉

一句话：〈这是什么地方，水或路从哪来到哪去，此刻是什么时辰〉
地貌：〈主体地形，最高处和最低处各是什么〉
水：〈形态：河 / 湖 / 海 / 泉 / 冰 / 没有水时用什么代替〉
植被：〈一种主体植物 + 一两种配角〉
生灵：〈主角一种，写出它在做什么〉；〈配角一两种〉
人迹：〈一处小建筑或一件器物，夜里亮不亮〉
空气：〈雾的浓淡、云的多少、有没有雨雪风沙〉
一奇：〈一件不可能、却很安静的事〉
色调：〈三四个主色 + 一个点缀色〉
最美时辰：〈拂晓 / 晨光 / 正午 / 黄昏 / 夜晚〉
必须出现 / 不要出现：〈有就写〉

容器：〈玻璃立方体 / 玻璃钟罩 / 玻璃球〉
背景：〈深空 / 桌面 / 纯色，写出颜色〉
光效：〈适中 / 柔和 / 强烈〉
系列名与题记：〈默认“方寸之境”〉
```

例（第一境按这个模板重写）：

```
方寸之境 · 第一境 · 雪山河谷

一句话：雪线化水，在高台上绕两个弯，越过断崖成瀑布，再绕过草甸流进湖里；清晨七点，斜光穿过山腰的云气。
地貌：后排五座雪峰，中间一道赭红色断崖，前面是平缓河谷。
水：一条河带一挂瀑布，汇入前景一面小湖。
植被：高台和河谷是阔叶林，山坡是针叶林，越近雪线越稀；草甸上有野花。
生灵：鹿群在河边草甸低头吃草；高台上有羊，湖畔有兔，湖面有鸭，山谷里有盘旋的鸟。
人迹：湖边一间红顶木屋，有栈桥和小船，入夜窗亮、烟囱冒烟。
空气：河谷晨雾、山腰云气、瀑布水雾，七朵云绕着山漂。
一奇：（第一境没有设，后续版本可补：比如夜里瀑布泛出极淡的蓝光。）
色调：草绿、赭红、雪白、湖青，点缀少量秋叶橙。
最美时辰：晨光。

容器：玻璃立方体。背景：深空。光效：适中。
```

## 二、九个槽位

| 槽位 | 要回答的问题 | 提醒 |
|---|---|---|
| 地貌主体 | 最高处是什么，最低处是什么，落差在哪 | 必须有一处明显高差，并让它切在剖面上 |
| 水的形态 | 水在哪里，怎么动 | 河要有来有去；没有水的题材（沙漠、雪原）找一样东西替它做“会流动、会反光”的角色：流沙、冰面、云海 |
| 植被 | 远看这一境是什么颜色和肌理 | 主体植物只选一种，新做它的形状 |
| 生灵 | 谁住在这里，在做什么 | 主角一种、配角一两种就够。写动作，不只写名字 |
| 人迹 | 人来过的痕迹 | 一处，小，旧。它通常是夜里的暖光，也是比例尺 |
| 天气与空气 | 雾、云、雨雪、风 | 决定这一境是通透还是氤氲 |
| 一奇 | 哪件事是不可能的 | 见下一节 |
| 色调 | 这一境的主色 | 和已有各境拉开：上一境是绿的，这一境就别再是绿的 |
| 最美时辰 | 开场停在什么时候 | 封面也用这个时辰 |

## 三、外观怎么选

用户写了就照用户的。用户没写，或者让你定，按这一境的内容来配：

- **容器看地形。** 起伏大、想让人看剖面的，用立方体，四面平直的剖面最清楚。中间高四周低（孤峰、海岛、火山）的，钟罩和球都合适。球会把地块外圈收平，所以四周本来就低的境装进去最自然；钟罩保留一圈直壁剖面，摆件感最强。
- **背景看气质。** 要“独立于世外”，用深空。要“摆在我桌上”的亲近感，用桌面。要干净、要配别的页面或品牌色，用纯色。
- **光效看发光体。** 夜景是主场、境里有灯火和发光的奇物，用强烈。白天清爽为主，用柔和。拿不准用适中。
- **一个系列尽量统一。** 看 `系列境单.md` 里前面各境用的什么。要变就让变化有规律。

圆形容器里可用的地方比立方体小：钟罩越靠边顶越矮，球还要把外圈收平。所以选了钟罩或球，布局时把重要的东西收在离中心 3.8 以内，最高的东西放在正中附近。

拿不定时不用争论：先按一种做完，再用出图脚本的附加参数（`container=sphere&backdrop=desk`）各出一张给用户挑。世界文件只要按 `制作与避坑.md` 写成不依赖容器形状的，换外观不用改别的。

## 四、一奇

魔法现实主义的意思是：一切都很平常，只有一件事不可能，而画面里没有谁为此大惊小怪。

每一境只设**一件**，它应该：

- **具体**：能用一句话说清是什么东西在做什么。“梦幻的氛围”不算。
- **安静**：不闪、不炸、不抢镜。第一眼可能没发现，凑近或者等到某个时辰才看到。
- **从这一境里长出来**：用的是这一境本来就有的东西，只是让它做了一件做不到的事。
- **有时辰**：最好只在某个时辰发生或者最明显，给人一个把滑杆拖过去看的理由。

可以这样找：这一境里的水、光、活物、器物，哪一样可以**反过来**（瀑布往上流）、**错位**（鱼在云里游）、**多出来**（湖里的月亮比天上多一个）、**停住**（一片叶子悬在半空不落）、**连起来**（鹿角上长着和山上一样的树）？

写进方案时写明三件事：是什么、什么时辰最明显、怎么实现（用到哪几个物体和什么动作）。

## 五、布局

世界是 10×10 的一块地（x、z 都在 −5 到 5），默认镜头从 +x、+z、偏上的方向看过来。所以：

- **后面和左边放高的**（山、崖、高树），**前面和右边放低的、有细节的**（水、草甸、地标、主角）。高的东西放在前面会把后面全挡住。
- **视线的落点放在中心偏前**（x、z 在 0 到 2.5 之间）：水的汇聚处、地标、主角通常在这里。
- **让地形的起伏切到剖面上**：山脊延伸到后边缘，河谷或水面靠近前边缘，剖面轮廓才好看。水体本身离边缘至少 1 个单位（海面除外，海是整块铺满的，会露出水的剖面）。
- **上面留空**：地表基准高度用 `meta.ground` 调。山高就把地面放低（−2.8），地势平就抬高（−1.6）。最高点不要超过 y = 3.2，上面留给云和光柱。
- **给活物留空地**：树林里留出几块草甸，主角站在空地上才看得见。

写三个候选布局再选一个。三个之间要有真的差别（水的走向不同、高处的位置不同、落点不同），不是同一个布局的三种措辞。

## 六、候选题材

挑题材时看和已有各境的差别：地貌类型、水的形态、主色、季节、最美时辰，至少有三项不同。

| 境名 | 地貌与水 | 主色 | 可以想的一奇 |
|---|---|---|---|
| 沙海绿洲 | 新月形沙丘环着一眼泉 | 沙金、赭石、一点翠绿 | 夜里沙丘的纹路像水一样缓缓流动 |
| 珊瑚海岛 | 海面铺满，一座小岛，水下有礁盘（海水剖面可见） | 青绿、白沙 | 黄昏时一头鲸的影子从玻璃壁里的水体中游过 |
| 火山温泉 | 一座锥形火山，山脚几处冒汽的泉眼 | 玄黑、硫黄、橙红 | 熔岩流到山腰变成一条开花的溪 |
| 极光冰原 | 冰盖、裂隙、浮冰的海 | 冰蓝、雪白 | 极光垂下来，末端落在冰面上像帘子 |
| 江南水乡 | 平地，水巷交织，拱桥，荷塘 | 粉墙黛瓦、烟青 | 雨只下在一条巷子里 |
| 梯田茶山 | 层层梯田顺山势盘上去，田里蓄水 | 嫩绿、水光 | 清晨每一层田里映出的天色都不一样 |
| 竹海禅院 | 缓坡上整片竹林，林间一条石径 | 竹青、苔绿 | 风过的时候，只有一竿竹子不动 |
| 喀斯特峰林 | 一根根石峰立在平田里，一条江绕着走 | 黛青、稻黄 | 江里的倒影比山多出一座 |
| 樱谷 | 浅谷，溪流，两岸花树 | 樱粉、新绿 | 落下的花瓣在水面上聚成一条逆流而上的线 |
| 秋枫栈道 | 深峡，崖壁上挂着栈道 | 枫红、岩灰 | 一片红叶悬在峡谷正中不落 |
| 草原星夜 | 低缓的丘，弯曲的河，一顶帐篷 | 草绿、夜蓝 | 入夜后河里流的是星星 |
| 盐湖天镜 | 极平的浅水盐滩，远处低山 | 天色、盐白 | 倒影里的云比天上的云走得慢 |

这张表是引子，不是清单。用户有自己的题材时以用户的为准。
