# 方寸之境 · 风格规范

这份文件写的是整个系列不变的部分，以及用户可以从预设里选的部分。它们都做在引擎里，你要做的是别去破坏它们，并且让自己做的东西跟它们是同一种质感。

## 一、是什么

一只透明玻璃容器（默认是悬浮在深空里的立方体），里面装着一方完整的小世界：有地、有水、有活物、有天气，从清晨到深夜循环。看起来像摆在桌上的微缩摆件，被一支微距镜头凑近了拍。

气质三个词：**宁静、精致、有一点不可能**。不热闹，不卡通，不写实。

## 二、用户可以选的外观（引擎提供预设）

写在 `world.js` 的 `meta.look` 里。每一种组合都出图验证过，所以只能从预设里选，不能随手写一个新的。

| 项 | 预设 | 各自的样子 | 适合 |
|---|---|---|---|
| 容器 `container` | `cube` 立方体（默认） | 方形地块，四面平直的剖面，棱边有分色细光 | 地势起伏大、想突出剖面的境 |
| | `dome` 钟罩 | 圆形地块，一圈直壁剖面，上面是半球罩，底沿一圈亮线 | 摆件感最强；中间高四周低的境 |
| | `sphere` 球 | 圆形地块，外圈收平贴住玻璃，地下是一只顺着球面的碗 | 雪景球、水晶球；海岛、雪山 |
| 背景 `backdrop` | `space` 深空（默认） | 近黑的蓝紫渐变、极淡星云、虚化光斑；容器悬浮并轻微浮动 | 默认，最有“独立世界”的感觉 |
| | `desk` 桌面 | 暖色暗房间，容器落在木桌上，带木底座（球是托座），有落影；不浮动 | “桌面摆件”的直观版本，暖 |
| | `plain` 纯色 | 一个颜色的上下渐变（`backdropColor`），没有光斑 | 要嵌进网页、要配品牌色、要干净 |
| 光效 `glow` | `normal` 适中（默认） | 轻微辉光 | 大多数境 |
| | `soft` 柔和 | 几乎没有辉光，玻璃边光更淡 | 白天为主、清爽的境 |
| | `strong` 强烈 | 明显的泛光弥散，玻璃边光更亮 | 夜景、发光体多的境 |
| 文字 | `meta.title`、`meta.tagline` | 左上角的系列名和题记 | 用户想用自己的系列名时改 |

同一个系列里建议容器和背景保持一致，这样各境摆在一起才是一套；要变化就让它有规律（比如冬天的境都用球）。

## 三、由引擎保证的（不随外观变）

| 项 | 规定 | 为什么 |
|---|---|---|
| 玻璃 | 直径约 10 的玻璃容器；边缘（立方体的棱、钟罩和球的轮廓）有分色折射的细光和游走的光点，偶尔一下星芒 | 系列的识别物。玻璃只在边缘被看见，面上几乎透明，不能挡住里面 |
| 地块 | 世界是一整块“切下来的地”：顶面是地貌，侧面是分层的土层剖面，填满容器底部 | 剖面是“摆件感”的来源，没有它就只是一个普通场景放进了盒子 |
| 镜头 | 透视相机、视角 20°，从右前上方俯看，可拖拽旋转、滚轮缩放；默认缓慢自转 | 窄视角接近等距视图的规整，又保留纵深，移轴才有东西可虚 |
| 移轴 | 画面上下两端虚化，中间一条清晰带；可开关、可调焦平面 | 微缩感的主要来源 |
| 昼夜 | 一天循环，十个时辰关键帧；太阳从左后方升起（逆光，光柱朝镜头），夜里换月光 | 每一境都要经得起从早看到晚 |
| 光 | 主光带软阴影 + 天光 + 始终从镜头对面打来的轮廓光；色调映射用 ACES | 柔和高光和勾边 |
| 空气 | 贴地薄雾、斜穿容器的光柱、漂浮尘埃、容器内随时辰变色的一层天色 | 体积感。雾和光柱在晨昏最浓，正午收敛 |
| 背景 | 不管选哪种，都是暗的、虚的，容器背后有一团光晕 | 把视线留在容器里 |
| 后期 | 轻微辉光、暗角、胶片颗粒、边缘色散 | 电影感，但都压得很低 |
| 界面 | 左上：系列名、“第 N 境 · 境名”、一句题记；右上：时刻和时辰名；底部一条胶囊面板；H 键隐藏 | 界面要安静，不抢画面 |
| 尺度 | 容器 10 个单位；树高 0.3–0.5，大型动物 0.13 左右，房子 0.25 左右 | 全系列的东西摆在一起大小一致。动物比真实比例略大，否则看不见 |

## 四、每一境重新做的（你负责）

题材、地貌、水的形态、植被、生灵、人迹、天气与空气的浓淡、色调、最美的时辰，以及**一奇**。详见 `造境指南.md`。

三样东西必须在这一境的 `world.js` 里新做，不能用现成的凑：

1. **主角生灵**：这一境最想让人凑近看的活物。
2. **地标**：一处人迹或一件器物，夜里通常是唯一的暖光。
3. **主体植被**：决定这一境远看是什么颜色、什么肌理的那一种植物。

配角（草、野花、石头、飞鸟、蝴蝶、云、雾、萤火）用引擎自带的，只调颜色、数量和位置。

## 五、质感：黏土和半透明

- **固体是黏土**：哑光（粗糙度 0.7–0.9），不反光，颜色饱满但不刺眼。形体用球、胶囊、圆锥、圆柱这些基本体捏出来，边角是软的，表面可以有一点手捏的起伏。不用贴图，不用外部模型。
- **半透明的只有四样**：玻璃、水、云雾、发光体（窗、萤火、这一境的奇物）。别的东西不要透明。
- **颜色成套**：一境选一组主色（三四个相近的色相）加一两个点缀色。地面颜色用噪声在两三个邻近色之间过渡，不要一块纯色，也不要一地杂色。
- **细节靠数量和层次，不靠单体精度**：近千棵树、近万丛草、上千朵花，每一样都有大小、朝向、颜色的随机差异。单个物体保持简单。

## 六、动：都很慢

- 草和树冠随风微摆；水有流向，瀑布和急流起白沫；云绕着山漂；雾缓缓挪动。
- 活物有自己的小动作：低头、踱步、跳一下歇一下、绕圈游。动作幅度小、周期长，不要整齐划一（每只给不同的相位）。
- 没有突然的东西：没有闪烁、没有快速位移、没有镜头晃动。

## 七、容易出的错

- **做成了示范境的翻版**：又是山、又是鹿、又是小木屋。先写方案再看示范。
- **奇事太吵**：会动的大东西、强烈的光效、整屏的粒子。一奇应该是安静的，第一眼可能没注意到。
- **太满**：把容器塞到顶。上方至少留四成是空气，让云、光柱和雾有地方待。
- **太平**：地势没有高低，剖面就是一条直线，很无聊。至少有一处明显的高差，并且让它落在剖面上能看见。
- **高的东西挡在前面**：默认镜头从 +x +z 方向看，山和高树放在后面（z 为负）和左边，水和细节放在前面。
- **夜里一片黑**：夜晚至少要有三种光：月光勾边、一处暖窗或灯、会动的微光（萤火或奇物）。
- **正午发白**：雪、沙、白墙面积大时，正午容易过曝。用 `sky()` 把那一境正午的主光压一点，或者把白色调灰一点。
- **雾盖住了水**：见 `制作与避坑.md`。
- **圆形容器里东西放得太靠边**：钟罩和球越靠边顶越矮，引擎会把边上的山压低，球还会把外圈收平。重要的东西（地标、主角、水）放在离中心 3.8 以内。

## 八、验收清单

出图后逐条看，四个时辰都要成立：

1. 容器完整在画面里，上下左右都有留白；玻璃的边缘看得见但不抢眼。
2. 剖面能看到分层，地表轮廓有起伏。
3. 第一眼知道这是什么地方；视线有一个落点（通常是水的汇聚处或地标）。
4. 主角生灵、地标、一奇在近景里各自成立，凑近看形体是完整的、落在地上的（没有悬空、没有埋进地里）。
5. 水是水的颜色，岸边有浅色过渡；没有大片发白或发黑。
6. 晨光或黄昏时看得见光柱和薄雾；正午干净；夜里不是一片黑。
7. 上方有足够的空气；没有东西穿出玻璃。
8. 控制台没有报错；拖拽、缩放、时辰滑杆、播放暂停、H 键都正常。
9. 和系列里已有的各境摆在一起，是同一套，但不是同一境。
10. 用户选的外观（容器、背景、光效、系列名）和成品一致。
