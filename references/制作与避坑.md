# 方寸之境 · 制作与避坑

写 `world.js` 之前读这一份。目录：一、文件怎么组成；二、坐标与尺度；三、外观预设与容器无关的写法；四、`F` 的工具；五、常见做法；六、预览与出图；七、性能；八、踩过的坑。

## 一、文件怎么组成

```
P/world.js          你写的：这一境的全部内容
$SKILL/core/        引擎：fangcun.js（逻辑）+ template.html（页面壳）
build.py            把三者合成一个单文件 HTML
```

`world.js` 的形状是固定的：

```js
const WORLD = {
  meta: { no, name, tagline, seed, ground, startHour, look: { container, backdrop, glow } },
  sky(k){ /* 可选：微调这一境的天色 */ },
  build(F){ /* 用 F 造这一境 */ },
};
```

- 文件里只写这一个 `const WORLD = {...}`，不写 `import` 和 `export`。构建时它被放进引擎所在的同一个模块里，`THREE` 等都从 `F` 里取。
- `build(F)` 里**必须调用一次 `F.terrain(...)`**，并且要在用到地形的工具（`F.ground`、`F.scatter`、`kit.*`）之前。
- `meta` 的可选项：`title`（系列名，默认“方寸之境”）、`azimuth`、`polar`（默认镜头角度，弧度，默认 0.66 和 1.06）、`speed`（昼夜快慢，默认 0.27 小时每秒）、`noiseSeeds`（两个整数，固定噪声形状；不写就从 `seed` 推出）、`rim`（容器是球时地块外圈收到的高度，默认 0.25）。
- 引擎从哪里取：`P/_core/` → `<系列目录>/_core/` → 技能自带的 `core/`。前两处是用户自己的风格（见 `自成一格.md`）；有的话，先读那里的 `风格.md`。

## 二、坐标与尺度

- 地块：x、z ∈ [−5, 5]，y 向上。玻璃立方体是 ±5.06，土层底面 y = −5。容器是钟罩时地块是半径 5 的圆，是球时是半径约 4.9 的圆（见第三节）。
- `G = meta.ground`（默认 −2.4）是地表基准。地形函数 `base(x, z)` 返回的是**相对 G 的高度 h**，实际高度是 `G + h`。`T.getH` 返回 h，`T.getY` 返回实际 y。
- 默认镜头在 +x、+z、偏上方向。后面是 z 为负，左边是 x 为负。
- 最高点建议不超过 y = 3.2（h ≈ 5.6，G = −2.4 时）；云在 y = 2.5–3.7。

| 东西 | 尺寸（单位） |
|---|---|
| 树 | 高 0.3–0.5 |
| 灌木、草丛 | 高 0.05–0.1 |
| 大型动物（鹿、羊） | 肩高 0.1–0.13，身长 0.12–0.15 |
| 小动物（兔、鸭） | 0.04–0.06 |
| 鸟、蝴蝶 | 0.03–0.05 |
| 房子 | 宽 0.2–0.3，高 0.25 |
| 河 | 宽 0.1（源头）到 0.5（下游） |
| 湖 | 半径 0.8–1.5 |

动物比真实比例大两三倍是故意的，照真实比例做出来只有几个像素。

## 三、外观预设与容器无关的写法

```js
meta: {
  look: { container: 'cube', backdrop: 'space', glow: 'normal' },      // 都是默认值，可以整项不写
  // container: 'cube' 立方体 | 'dome' 钟罩 | 'sphere' 球
  // backdrop:  'space' 深空 | 'desk' 桌面 | 'plain' 纯色（另写 backdropColor: '#10131a'）
  // glow:      'normal' 适中 | 'soft' 柔和 | 'strong' 强烈
}
```

写错预设名不会报错中断：引擎在控制台给出提示并改用默认值，`shot.sh` 会把这条提示打印出来。

**圆形容器（钟罩、球）和立方体的差别：**

| | 立方体 | 钟罩 | 球 |
|---|---|---|---|
| 地块 | 10×10 的方 | 半径 5 的圆 | 半径约 4.9 的圆 |
| 顶 | 平顶 y = 5.06 | 半球：正中 5.06，离中心 4 处只有 3.1，边上 0.8 | 球面：正中 5.44，离中心 4 处 3.7，边上约 2.3 |
| 边上的地形 | 原样 | 太高的山被压到玻璃下面 | 同左，并且外圈（离中心 3.8 以外）被收平到 `meta.rim` 的高度 |
| 剖面 | 四面平直 | 一圈直壁 | 顺着球面收下去的一只碗 |
| 背景是桌面时 | 方木底盘 | 圆木底盘 | 木托座 |

所以**世界文件要写成不依赖容器形状的**，用户才能改一个词就换容器：

- 撒东西用 `F.scatter`、`kit.*`（它们自己会避开地块外面）。自己写循环时先问 `F.inFoot(x, z)`。
- 放高的东西（塔、高树、飞的东西、云以外的悬浮物）先问 `F.ceiling(x, z)`，它返回那一处玻璃顶的 y；或者直接用 `F.fits(x, y, z)`。
- 自己写的粒子着色器里引入 `${F.glslInside()}`，用 `insideC(p)` 乘到透明度上，粒子就只出现在玻璃里面（示范见第二境的落雪）。
- 重要的东西（地标、主角、河和湖、一奇）放在离中心 3.8 以内。这个范围在三种容器里都完好。
- 自己加的大块平面（冰面、熔岩面）用 `F.flatGeo`，不要用方形的 `PlaneGeometry`：方的在立方体里角被地形盖住看不出来，换成圆形容器就会从地块边上伸出去。
- 不要在世界文件里写 `if (容器是球)`。需要知道时用 `F.ROUND`（是不是圆形容器）、`F.footR()`（地块半径）、`F.look`。

## 四、`F` 的工具

从 `F` 里解构常用的：`const { THREE, G, R, pick, rand, C, gs, smooth, clamp, lerp, n2, fbm, ridged, kit } = F;`

### 数学与随机

| | |
|---|---|
| `rand()`、`R(a, b)`、`pick(数组)` | 由 `meta.seed` 决定的随机数，每次构建结果一样。**不要用 `Math.random()`**，否则每次刷新都不一样，出图对不上 |
| `n2(x, z)`、`F.n2b(x, z)` | 两套平滑噪声，值在 −1 到 1 |
| `fbm(x, z, 层数)` | 叠加噪声，−1 到 1 左右：自然起伏、颜色斑驳 |
| `ridged(x, z, 层数)` | 山脊噪声，0 到 1：山的棱线 |
| `gs(dx, dz, r)` | 高斯鼓包：`h += 2.5 * gs(x - 1, z + 3, 1.2)` 就是在 (1, −3) 放一座半径约 1.2、高 2.5 的山 |
| `smooth(a, b, x)` | 平滑阶跃，a 可以大于 b（反向） |
| `C('#hex')` | 新建颜色 |

### 地形 `F.terrain(opt)` → `T`

```js
const T = F.terrain({
  base: (x, z) => h,                                   // 必填：原始地形
  rivers: [{ points: [[x, z], ...], lake: 0,           // 从源头到终点的一串点；lake 是它流入的湖在 lakes 里的序号
             width: [0.055, 0.245], depth: [0.07, 0.17] }],   // 源头→下游的半宽和水深（可省）
  lakes: [{ x, z, rx, rz, depth: 0.45 }],              // 椭圆湖；水位取流入河的水位，没有河就取湖心地面略低
  sea: { level: 0.3 },                                 // 海面（相对 G）。低于它的地方都是水，四面会露出水体剖面
  pads: [{ x, z, r: 0.6 }],                            // 把一块地整平，放建筑
});
```

河是这样算的：沿你画的线取地面高度，水位“只降不升”。所以线经过陡坎会自动变成瀑布，经过小丘会切出峡谷，河床和河岸自动修好。你只管把线画得合理：从高处画到低处，想要瀑布就让线垂直穿过一道崖。

`T` 上能用的：

| | |
|---|---|
| `T.getH(x, z)`、`T.getY(x, z)` | 相对高度 / 实际高度 |
| `T.slopeAt(x, z)` | 坡度，0 是平地，0.3 是明显的坡，0.6 以上是崖 |
| `T.isDry(x, z, 余量)` | 不在河里、湖里、海里 |
| `T.lakeDist(x, z)` | 到最近一个湖的归一化距离，小于 1 在湖里，1.5 以内算湖边；没有湖时是无穷大 |
| `T.lakeE(湖, x, z)` | 到指定湖的归一化距离 |
| `T.nearest(x, z, 最大距离)` | 最近的河道点：`{ d 距离, k 序号, r 所属的河 }`，没有则 null |
| `T.rivers[i]` | `pts`（采样点）、`level`（各点水位，相对 G）、`wid`（半宽）、`PS`（点数）、`fallBase` / `fallTop`（最大落差处的底和顶，实际坐标）、`fallHeight` |
| `T.lakes[i]` | `x, z, rx, rz, level`（水位，相对 G） |
| `T.sea` | `{ level }` 或 null |

### 地表与水

```js
F.ground({
  color(c, x, z, h, slope){ ... },          // 改写 c（THREE.Color）给每个顶点上色
  strata: F.makeStrata({ ... }),            // 可选：这一境的土层色带（也会用在四面剖面上）
  shore: { sand, bed, deepBed },            // 可选：岸边、浅水底、深水底的颜色
  topsoil: ['#3d2a1d', '#5e3f29'],          // 可选：剖面最上面那层表土
});
F.water({ shallow: '#7fd6c6', deep: '#1e5a78' });   // 河带、湖面、海面一起建好
```

- `F.strata(yy, x, z, out)`：默认色带。`yy` 是相对 G 的高度，≥0 是山体断面（暖色条带循环），<0 是地下土层。**陡坡的颜色用它**（`c.lerp(F.strata(h, x, z, tmp), smooth(0.34, 0.6, slope))`），崖壁才会和四面剖面是同一套岩层。
- `F.makeStrata({ canyon: [色…], rocks: [色…], soil: [[深度, 色], …], rockLine, band })`：换一套色带。沙漠用沙黄和橘红，冰原用几种蓝白，火山用黑和暗红。`soil` 的深度是负数，从 0 往下排。
- 水下和岸边的颜色由 `F.ground` 自动处理，`color()` 里不用管。

### 摆东西

| | |
|---|---|
| `F.scatter({ max, tries, range, accept(x, z, h) })` | 随机撒点，返回 `[[x, z, h], …]` |
| `F.instances(几何体, 材质, 列表, (o, 项, i) => { 设 o.position / rotation / scale; return 颜色 })` | 大量重复的东西用它，一次绘制。超过几十个的东西都应该用它 |
| `F.findSpot(x0, z0, 半径)` | 在某处附近找一块干燥的平地，返回 `[x, z]` |
| `F.place(物体, x, z, 抬高)` | 放到地面上 |
| `F.clay('#hex', { 额外参数 })` | 黏土材质（同色共用） |
| `F.blob([[半径, x, y, z], …])` | 几个球揉成一团：树冠、云、羊毛、灌木、石堆 |
| `F.wind(材质, 强度, 频率)` | 让材质随风摆。几何体按“高度 1”建模，底在 y = 0 |
| `F.shadowAll(组)` | 让一组物体都投影和受影 |
| `F.flatGeo(湖, y, 倍数)` | 贴着高度 y 的一片椭圆平面，盖住一个湖的范围，超出地块的部分自动收回。自己做冰面、熔岩面时用它，不要用方形平面 |
| `F.root` | 所有东西都加到它上面（不是 `scene`），才会跟着容器一起浮动 |
| `F.inFoot(x, z, 余量)` | 这个位置在地块里面吗（立方体是方的，钟罩和球是圆的） |
| `F.ceiling(x, z)` | 这个位置玻璃顶的高度（实际 y） |
| `F.fits(x, y, z, 余量)` | 这个点在容器里面吗 |
| `F.footR()`、`F.ROUND`、`F.look` | 地块半径、是不是圆形容器、当前的外观设置 |
| `F.glslInside()` | 一段着色器代码，提供 `float insideC(vec3 p)`：在容器里是 1，靠近玻璃渐变到 0 |

### 会动的和会亮的

```js
F.life((t, L, dt) => { ... });     // 每帧调用。t 是秒，L 是当前光照
F.onLight(L => { ... });           // 光照更新时调用：L.night（0–1 夜晚程度）、L.hour、L.key / L.sky（当前颜色）、L.ki（主光强度）、L.keyDir
```

夜里亮灯的标准写法：`F.onLight(L => { 窗材质.emissiveIntensity = L.night * 3.2; 点光.intensity = L.night * 0.45; });`

只在某个时辰出现的东西（一奇常常如此）用 `L.hour` 或 `L.night` 控制透明度或缩放，让它渐入渐出。

### 空气

| | |
|---|---|
| `F.clouds({ count, y: [低, 高], r: [内, 外], scale: [小, 大] })` | 绕中心慢慢漂的云 |
| `F.mist(x, y, z, 大小, 浓度, { type, rise, tint })` | 一团雾。`type: 1` 是往上升的（`rise` 是上升高度），`tint: 1` 偏灰（烟） |
| `kit.mistLayer({ count, accept(x, z, h), lift, size, alpha })` | 贴地薄雾层 |
| `kit.plume(位置, { count, spread, size, alpha, rise, tint })` | 一股上升的：瀑布水雾、温泉蒸汽、炊烟 |
| `F.firefly(x, y, z)`、`kit.fireflies({ max, accept })` | 萤火，夜里才亮 |

光柱和漂浮尘埃是自动的。

### 现成的配角 `kit`

| | |
|---|---|
| `kit.grass({ max, accept, color(x, z, h), size })` | 草丛，随风 |
| `kit.flowers({ max, accept, colors, size })` | 野花（小圆点） |
| `kit.rocks([[x, z, 大小], …], 颜色数组)` | 石头 |
| `kit.birds(n, { center, r, y, colors })` | 盘旋的鸟 |
| `kit.butterflies([[x, z], …], 颜色数组)` | 白天的蝴蝶 |
| `kit.trees(列表, { canopy, trunk }, 颜色函数, [小, 大], 树干色)` | 种树。几何体可以用 `kit.treeGeo('broadleaf' 或 'conifer')`，但**主体植被请自己做一组 `{ canopy, trunk }`**（竹子、棕榈、樱树、仙人掌……），底在 y = 0、总高约 1 |

### 天色 `sky(k)`

```js
sky(k){ k.noon.ki = 2.8; k.noon.sky = '#e8f0ff'; k.sunset.haze = '#ffb07a'; k.night.mist = '#5a6ab0'; }
```

十个时辰：`midnight predawn daybreak sunrise morning noon afternoon sunset dusk night`。每个可改：`key` 主光色、`ki` 主光强度、`sky` / `gnd` 天光和地面反光色、`hi` 天光强度、`rim` / `ri` 轮廓光、`mist` 雾色、`ma` 雾量、`sh` 光柱强度、`haze` / `ha` 立方体内的天色和浓度、`exp` 曝光。不要改时刻 `h`。改夜晚时 `midnight` 和 `night` 一起改，它们首尾相接。

## 五、常见做法

**一座山**：`h += 高 * gs(x - cx, z - cz, 半径)`，几座叠起来；再乘一个 `0.8 + 0.4 * fbm(...)` 打破对称，加一点 `ridged(...)` 做棱线。

**一道崖**：`h += 台高 * smooth(线 + 软, 线 − 软, z)`，`软` 越小越陡（0.08 近乎垂直，1.0 是缓坡）。线可以是 x 的函数，让崖弯起来。

**梯田 / 台地**：`h = Math.round(h0 / 层高) * 层高` 再和 `h0` 混一点，保留很窄的坡面。

**沙丘**：`Math.abs(Math.sin(...))` 做不对称的波，叠两个方向。

**主体植被新做**：做 `canopy` 和 `trunk` 两个几何体交给 `kit.trees`。比如竹子：`trunk` 是细长圆柱，`canopy` 是顶上几片 `F.blob` 压扁的叶团。

**捏一只动物**：一个 `Group`，身体用胶囊或压扁的球，腿用细圆柱，头单独放在一个“脖子根”的子 `Group` 里（转这个子组就是低头、抬头）。眼睛、耳朵、尾巴是小球小锥。整体 `scale.setScalar(...)` 调到上表的尺寸。完整例子见示范境的 `makeDeer`。超过十几只的同种动物改用 `F.instances`。

**绕圈走的活物**：`F.life(t => { const a = a0 + t * w; x = cx + cos(a) * r; z = cz + sin(a) * r; 物体.position.set(x, T.getY(x, z), z); 物体.rotation.y = -a - sign(w) * PI / 2; })`。每只的 `a0`、`w`、`r` 都随机，别同步。

**降水（雪、雨、花瓣）**：引擎里没有，在 `world.js` 里用 `THREE.Points` 加一个自己的着色器。要点：位置用取模做循环下落；顶点着色器里引入 `F.GLSL_HEIGHT`、传入 `uHeight: F.surfU`，用 `terrainY(p.xz)` 判断，落到地面以下就透明；点的大小乘一个“每单位多少像素”的系数，在 `F.life` 里每帧算（`innerHeight × 像素比 ÷ (2·tan(视角/2))`）；亮度在 `F.onLight` 里跟着天光走。完整写法见第二境《雪落寒山》的落雪。

**发光的东西**：材质设 `emissive` 和 `emissiveIntensity`（大于 1 会被辉光晕开）。要照亮周围再加一个 `PointLight`（不开阴影，全场不超过三四个）。

## 六、预览与出图

```bash
python3 $SKILL/scripts/build.py P                 # → P/out/preview.html
sh $SKILL/scripts/shot.sh <html> <输出.png> [时辰=17.6] [宽=1600] [高=2000] ["附加参数"]
```

`shot.sh` 用无界面 Chrome 直接打开本地文件，自动隐藏界面、停住时辰和自转，等场景建好后截图。截出来的图用 Read 工具打开看。

页面支持这些网址参数（`shot.sh` 的附加参数、手动预览时都能用）：

| 参数 | 作用 |
|---|---|
| `hour=17.6` | 起始时辰 |
| `pause=1` | 时辰不走 |
| `rot=0` | 不自转 |
| `ui=0` | 隐藏界面 |
| `intro=0` | 跳过开场推镜 |
| `tilt=0` | 关移轴 |
| `az=0.66`、`pol=1.06` | 镜头方位角、俯仰角（弧度；`pol` 越小越俯视，1.57 是平视） |
| `dist=0.5` | 距离倍数，小于 1 是推近 |
| `tx= ty= tz=` | 镜头注视点。**近景要同时给注视点和 `dist`**：`"tx=2.3&ty=-1.9&tz=2.3&dist=0.3"` |
| `shot=1` | 出图模式（等于 `pause=1&rot=0&ui=0&intro=0`） |
| `container=`、`backdrop=`、`glow=` | 临时换外观预设，不用改文件。给用户比较几种外观时用：`"container=sphere&backdrop=desk"` |

在浏览器里手动检查时，控制台有 `window.__fangcun`：`__fangcun.state.hour = 22` 改时辰，`__fangcun.camera`、`__fangcun.controls` 摆镜头，`__fangcun.F.T` 查地形。

用浏览器工具预览时要通过 `http://localhost` 打开（在系列目录里 `python3 -m http.server <端口>`）；有的预览窗格打开本地文件只给静态快照，看起来是一片黑。窗格在后台时帧率会被压得很低，这时测出的帧率不算数。

## 七、性能

目标是普通笔记本上 60 帧。引擎本身（阴影、后期、雾）已经占了一部分，世界文件的预算大致是：

- 树 1000 棵以内，草 10000 丛以内，花 1500 朵以内，全部走 `F.instances`。
- 单独的 `Mesh`（动物、建筑的零件）总数控制在 1500 个以内。
- 带阴影的点光源不要加；不带阴影的点光源不超过四个。
- 自己写的每帧逻辑里不要新建对象（`new THREE.Vector3()` 放到外面）。
- 不要加第二套后期或者全屏透明层。

## 八、踩过的坑

这些都是做第一境和引擎时真的出过的问题。引擎里已经处理的，知道原因是为了别在世界文件里再犯一次。

1. **雾盖住了水面。** 雾粒子靠“离地面多高”来淡出，水面下方的地面很深，所以水上的雾一点不淡，堆成一片白，看起来像水坏了。引擎已经改成按“地面和水面取高者”计算，但水上仍然只适合放很薄的雾：`mistLayer` 的 `accept` 里加 `T.isDry(x, z, 0) && T.lakeDist(x, z) > 1.5`，湖面要雾就单独加几团浓度 0.05–0.1 的。
2. **晨昏时水发白是正常的。** 水面反射的是天光，日出日落的天是暖白色。判断水有没有问题看正午那张。
3. **高度数据纹理要设 `unpackAlignment = 1`。** 宽度不是 4 的倍数的单通道纹理，不设这一项会逐行错位（引擎已设；你自己建数据纹理时记得）。
4. **平面玻璃会整面一起反光。** 窄视角下一个平面上各点的反射方向几乎相同，太阳一对上，整个面全白。引擎用斜向条带把高光打散了。你在世界里放大块平面反光物（冰面、镜子）会遇到同样的事：粗糙度别低于 0.3，或者让表面有一点起伏。
5. **页面在后台加载时窗口尺寸是 0。** 用宽高比算出来的东西会变成无效值。引擎已保护；你在 `build` 里不要用 `innerWidth`、`innerHeight`。
6. **河入海后不该再修河床。** 引擎在河线入海处停止（`kSea`）。河线的最后一个点可以直接画到海里。
7. **河线画反了或者画过了山脊**，会切出一条很深的峡谷（水位只降不升）。先把 `base` 的形状定好，再沿着低处画线；画完看一眼 `T.rivers[0].fallHeight`，它是最大的一处落差。
8. **东西悬空或者埋进地里。** 放在地面上的物体一律用 `T.getY(x, z)` 取高度；在坡上的建筑先用 `pads` 把地整平。水上的东西用 `G + 湖.level`。
9. **随机数用了 `Math.random()`**，每次打开都不一样，出图和交付的对不上。用 `rand` / `R` / `pick`。
10. **取景太满。** 默认距离已经给立方体四周留了白。出封面时 `dist` 不要小于 0.85，否则棱角会被裁掉。
11. **`world.js` 里写了 `</script`**（比如在字符串里），页面会被截断。`build.py` 会报错提醒。
12. **出图整片发黑**，多半是 `world.js` 里脚本报错了（出图模式下加载幕不显示，所以只剩黑）。`shot.sh` 会把页面报错打印出来，先看它。
13. **`F.blob` 出来的几何体没有顶点索引**，圆锥、圆柱、方块有。把它们用 `F.mergeGeometries` 合并之前，先对后者调用 `.toNonIndexed()`，并 `deleteAttribute('uv')`，否则合并失败、整页报错。
14. **`fallTop` / `fallBase` 不在崖面上。** 它们是河道“开始变陡”和“重新变缓”的位置，前者在崖后的沟里，后者在崖脚外面一段。要在崖面上挂东西（冰瀑、藤蔓、栈道），沿 `river.pts` 找水位降到落差九成和一成的两个点，才是崖沿和崖脚。写法见第二境的冰瀑。
15. **雪、沙、盐这类浅色地面会被晨昏的天色染脏。** 默认的日出和日落是暖橙色，打在大面积白色上是灰褐一片。在 `sky()` 里把天光 `sky` 和地面反光 `gnd` 改成冷色（蓝紫），只留主光 `key` 是暖的，受光面和背光面就分开了；光柱 `sh` 也压到 0.5 以下。
16. **不想要活水时不调用 `F.water()`。** `F.terrain` 里照样可以写河和湖来挖河道和湖盆，河床和湖底的颜色由 `F.ground` 的 `shore` 决定，改成冰色就是冻溪和冰湖；冰面自己加一个平面。
17. **换成钟罩或球之后东西没了或者被压扁了。** 圆形容器会把靠边的高山压低，球还会把外圈收平；放在离中心 3.8 以外的地标、湖、主角会受影响。把它们往里挪，不要去改引擎的边界。
18. **球形容器里海面和地块外圈的关系。** 有海的境装进球里，引擎会自动把外圈收到海面以下 0.45，海水一直铺到玻璃；想让外圈露出水面，自己设 `meta.rim`。
