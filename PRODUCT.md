# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

static HTML/CSS/JS generated by a Python script (`gallery/build.py`), following the precedent of NEO-Cine's gallery; no framework.

## Users

- People who arrive from the owner's posts (Xiaohongshu, WeChat) or from GitHub and want to see what an isle looks like before anything else.
- People who use a coding agent (Claude Code first) and want to make their own isles: they need the fill-in brief, the look presets, and the install command.

## Product Purpose

NEO-Isle is an agent skill that builds interactive 3D miniature worlds ("isles", 境) as single-file web pages. Each isle is one self-contained small world inside a glass container that the visitor can turn, zoom, and watch pass from dawn to night. Success: someone reads the brief template, fills it in, and gets an isle that sits naturally beside the existing ones.

## Positioning

The engine is fixed and the world is written fresh each time: the container, day-night cycle, tilt-shift lens, mist, light shafts and soil cross-section are guaranteed by the engine; the subject (nature, city, medieval, cyberpunk) is open, always at the same small size. Looks are chosen from verified presets, not typed freely.

## Operating Context

- The skill lives in the owner's skill library; isles are built in a user's own folder as `<series>/<nn>-<slug>/`.
- Deliverables are versioned (`-v001`, `-v002`), never overwritten.
- The gallery is a static site meant for GitHub Pages, sibling to NEO-Cine's gallery (https://neohoy.github.io/neo-cine/).
- Pages load three.js from a public CDN at runtime.

## Capabilities and Constraints

- Three customization layers: content (free text in nine slots), look (presets: container cube / dome / sphere; backdrop space / desk / plain; glow soft / normal / strong; series title), own style (copy the engine into the user's series folder).
- Two isles exist: 01 Snow Valley (雪山河谷), 02 Snowfall Peak (雪落寒山). Planned subjects: miniature city, medieval, cyberpunk.
- Undecided: publication date; the repository `neohoy/neo-isle` and its Pages site do not exist yet; license is assumed MIT like the owner's other public skills and is not confirmed.
- Frame rate has not been measured on real displays.

## Brand Commitments

- Name: NEO-Isle. Chinese name: 方寸之境. The isle is a metaphor for a self-contained world.
- Part of NEO造物集 by neohoy, sibling of NEO-Cine ("NEO-Cine makes films, NEO-Isle makes worlds").
- Line: 用代码，造一方小世界.
- Documents are bilingual: English is the main file, a Chinese version sits beside it.
- The README follows NEO-Cine's README framework; the gallery is a place to preview isles and looks, like NEO-Cine's.

## Evidence on Hand

- Two finished isles with world files: `examples/01-雪山河谷/world.js`, `examples/02-雪落寒山/world.js`.
- Renders of every look preset for both isles (generated by `scripts/shot.sh`).
- No users, stars, testimonials or usage numbers exist; none may be invented.

## Product Principles

1. One isle at a time, each designed from its own brief.
2. The engine guarantees the feel; the author only writes the world.
3. Looks come from verified presets; anything else is a deliberate fork.
4. Check by looking at renders at four times of day, never by assumption.
5. Deliverables are versioned and belong to the person who made them.
